03 Evidence boundaries

Know what the tool
can actually prove.

Use Bcrypt Guard for structured evidence collection, followed by human review and server-side remediation.

Default postureDeny scope creepExplicit checks only
+

Inside the boundary

Built in

  1. 01Read-only GET, HEAD, and OPTIONS requests
  2. 02Same-origin redirects only
  3. 03Eight-second timeout and 256 KB response cap
  4. 04Bounded request counts with cancellation
  5. 05Tokens and cookies excluded from reports
−

Outside the boundary

Not built in

  1. 01No endpoint brute force or unrestricted crawler
  2. 02No password attack or credential spraying
  3. 03No browser payload execution
  4. 04No POST, PUT, PATCH, or DELETE request
  5. 05No claim that a site is vulnerability-free
!
Interpretation still matters.
